COMMUNITY EDITOR'S DESK

让好讨论，成为下一期。

选一份模板，带上你的材料。把 AI 初稿变成可以留下来的社区记录。

01 / 准备本期材料

材料只在当前浏览器中处理，不上传服务器，也不会自动保存。录音请先在常用工具中转写成文字。

下载 JSON 模板 ↓
02 / 导入初稿，预览与核对

将 AI 返回的 JSON 粘贴到下方，或从文件导入。这里负责排版和检查，不调用模型生成总结。

03 / 编辑审核与导出

导出文件后提交到仓库的 content/digests/，运行构建并推送。导出操作不会直接修改线上网站。任何内容改动后都需要重新预览、重新审核。

写一份值得读的日报

留住讨论的来龙去脉。

  1. 按主题，而非按时间抄写把相关观点组织成读者能理解的脉络。
  2. 保留不同意见谁提出问题，谁给出经验，哪里还没有答案。
  3. 让结论可以追溯摘录附时间；不确定的人名、数字不要猜。
  4. 把后续行动单独记下分清现场承诺与编辑建议，不替别人派任务。
